# Uber автовозов и эвакуаторов для дилеров.
## Elevator pitch
Перевозка машин с уходом официальных дилеров стала огромной проблемой, не так ли? Куча частников без гарантий, которых ищут простые менеджеры по группам в телеграмме . Никаких гарантий, а самое главное, что привезти 1-2 машины слишком дорого, долго или вообще невозможно. Да даже внутри страны не всегда можно найти выгодной эвакуатор, либо предусмотерть для него выгодный сложный маршрут. Мы предлагаем LTL модель для автомобилей. Все перевозчики проверены, привезти можно от 1 автомобиля не через месяц, а уже завтра, так как автовоз загружается не только вашими авто. А по России можно будет найти совместный эвакуатор по принципу uber. Такая модель позволяет значительно сокращать логистические издержки,снять с менеджеров(которые в этом мало понимают) отвественность поиска, и, что более важно, в разы ускоряет доставку авто.

# Роли и user stories
## Общие US
- создать аккаунт соотвествующий роли (must)
- безопасная сделка как для заказчика, так и для исполнителя (что-то вроде Авито доставки) (should)
- проверка документов (must)
- отчётность в ЛК для оценки расходов/доходов и объёма поставок (для админов оценка эффективности обработки обращений) (should)
- Возможно предложить/попросить скидку
- Получать готовые документы для упрощения юр. сопровождения (could)
### Заказчик (дилер)
- разместить заказ на перевозку (must)
- Присоединиться к готовящемуся рейсу (must)
- выбрать рейс не из спика, а по карте (could)
- оплатить заказ (must) 
- обратиться в поддержку для разрешения конфликтных ситуаций (must)
- Посмотреть аккаунт перевозчика (must)
- Оменить заказ (must)
- выбрать страховое агенство (should)
- иметь возможность оценить перевозчика (could)
- получать фото и точно отслеживать маршрут (could)
### Исполнитель (перевозчик)
- размезстить объявление о сборе на перевозку (must)
- Посмотреть документы на выкуп у дилера (must)
- Принять или отклонить запрос на перевозку (must)
- Получить оплату (must) 
- Совершать отметки о состоянии маршрута (must/should)
- продвигать в топ свои объявления по перевозкам (should)
- удобная карта для оптимизации маршрутов (сould)
- Разместить и изменить информацию об автовозе (must)
- Партнёские скидки специально для водителей автовозов (на заправках, мотели и т.д.) (could)
  
### Админстрация (поддержка для решения проблем и поддержания работы)
- Проверка документов для отсеивания мошенников (must)
- Закрывать заказы, сделанные по ошибке (must)
- Иметь доступ к информации по заказу с обеих сторон, и возможность общаться с исполнителем и заказчиком (must)

  # Наиболее важное из mvp
  ## размезстить заказ на перевозку/объявление о сборе на перевозку
  ### ФТ
- предоставляется форма для ввода обязательных парметров перевоки:
  для заказа на пе количество перевозимых авто, точка отправления, тип перевозимых авто, дата готовности отправить
  для объявления о сборе перевозки тип автовоза, количество свободных мест, зона готовности принять груз, предполагаемый маршрут
- Возможность выбрать желаемый тип автовоза 
- Форма с незаполненными обязательными полями не проходит
- Возможность прикрепить документы о выкупе
- У объявления есть статус и его можно отслеживать в ЛК (активно, модерация и тд)
- Отзыв/изменение формы пока она в модерации
- Система показывает условия публикации/отмены
### НФТ
- Продуманность форм, лёгкость их заполнения для любого человека
- Быстрое обновление статусов
- Быстрая публикация
- Автосохранение черновиков
- Возможность загружать документы в большом количестве форматов

## Оплатить заказ/получить оплату за заказ
### ФТ
- Эскроу
- Выбор метода оплаты
- Алёрт в случае неудачной оплаты
- Возможность ознакомиться с документами
- В случае подписки для перевозчиков при оплате показываются пейволл с преимуществами и дата след списания
- Напоминание о списании
- Генерация чека
- Уведомления об оплате на другую сторону
- Измение статуса оплаты после собственно оплаты
### НФТ
- Оплата работает быстро и удобна с учётом спицифики оплаты от юр лиц
- Удобные формы заполнения платёжных данных
- Сисема отказоустойчива. При проблемах всё не виснет, а выходит соотвестующее "успокоительное" окно

# Успех :)
## Дано
Заказчик находится экране объявления о перевозке по нужному маршруту
#### И 
У исполнителя есть достаточно свободных мест на рейса
#### И
У исполнителя есть достаточно средств 
#### И 
У авто всё в порядке с документами

## Когда
Заказчик нажимает кнопку забронировать

## Тогда
- Закрывается окно заказа, открывается окно брони (+ можно какое-то милое сообщение)
- В объявлении уменьшается количество доступных мест
- Заявка уходит на доп проверку документов выкупа
- На счету заказчика замораживается сумма за перевозку

- После успешной доп проверка исполнителю приходит пуш

# Неудача :(

## Дано
Заказчик находится экране объявления о перевозке по нужному маршруту
#### И 
У исполнителя есть достаточно свободных мест на рейса
#### И
У исполнителя есть достаточно средств 
#### И 
У авто не всё в порядке с документами (запрет рег. действий, залог, угон)

## Когда
Заказчик нажимает кнопку забронировать

## Тогда
- На моменте провальной проверки по базам выходит об отказе в бронировании из-за юр проблем (тоже можно что-то мило-грустное)
- Процесс бронированирования останавливается
- Окно с ошибкой можно закрыть и вернуться к поиску исполнителей
