# Uber автовозов и эвакуаторов для дилеров.
## Elevator pitch
Перевозка машин с уходом официальных дилеров стала огромной проблемой, не так ли? Куча частников без гарантий, которых ищут простые менеджеры по группам в телеграмме . Никаких гарантий, а самое главное, что привезти 1-2 машины слишком дорого, долго или вообще невозможно. Да даже внутри страны не всегда можно найти выгодной эвакуатор, либо предусмотерть для него выгодный сложный маршрут. Мы предлагаем LTL модель для автомобилей. Все перевозчики проверены, привезти можно от 1 автомобиля не через месяц, а уже завтра, так как автовоз загружается не только вашими авто. А по России можно будет найти совместный эвакуатор по принципу uber. Такая модель позволяет значительно сокращать логистические издержки,снять с менеджеров(которые в этом мало понимают) отвественность поиска, и, что более важно, в разы ускоряет доставку авто.

# Роли и user stories
## Общие US
- создать аккаунт соотвествующий роли (must)
- безопасная сделка как для заказчика, так и для исполнителя (что-то вроде Авито доставки) (should)
- проверка документов (must)
- отчётность в ЛК для оценки расходов/доходов и объёма поставок (для админов оценка эффективности обработки обращений) (should)
### Заказчик (дилер)
- разместить заказ на перевозку (must)
- Присоединиться к готовящемуся рейсу (must)
- обратиться в поддержку для разрешения конфликтных ситуаций (must)
- выбрать страховое агенство (should)
- Получать готовые документы для упрощения юр. сопровождения (could)
- иметь возможность оценить перевозчика (could)
- получать фото и отслеживать маршрут (could)
### Исполнитель (перевозчик)
- размезстить объявление о сборе на перевозку (must)
- продвигать в топ свои объявления по перевозкам (should)
- удобная карта для оптимизации маршрутов (сould)
### Админстрация (поддержка для решения проблем и поддержания работы)
- Проверка документов для отсеивания мошенников (must)
- Закрывать заказы, сделанные по ошибке (must)
- Иметь доступ к информации по заказу с обеих сторон, и возможность общаться с исполнителем и заказчиком (must)
